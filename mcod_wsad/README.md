# Schemat kolumn AED

`aed_constants.py` odzwierciedla wzorcowy zakres z `common/aed_columns.json`. Ich zgodność sprawdza `tests/test_wsad.py`.
Publikację realizuje polecenie `publikuj_aed` w aplikacji resources backendu mcod. Korzysta z modeli instytucji, zbioru, zasobu i pliku zasobu. Rejestracja instytucji, rola redaktora i dostęp służb są opisane w głównym README.
